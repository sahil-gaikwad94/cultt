# Asset notes

The optimized `.webp` images in `assets/images/` are local copies of Unsplash image-search results used as **illustrative sample profile and feed artwork**, not real Cultured members. The earlier responsive-web implementation placed these in `public/images/`; this native Expo app imports them from `assets/images/`.

| Local file | Search-result description | Intended fixture use |
| --- | --- | --- |
| `maya.webp` | Portrait of a young woman smiling in a denim jacket | Illustrative Taste Twin and chat profile |
| `sophie.webp` | Woman smiling outdoors | Illustrative Taste Twin and community post artwork |
| `leo.webp` | Young man portrait outdoors | Illustrative Taste Twin profile |
| `jules.webp` | Woman listening to music with headphones | Illustrative Taste Twin and feed avatar |
| `guitarist.webp` | Young man playing guitar outdoors | Illustrative community post artwork |
| `singer.webp` | Singer performing on stage | Illustrative feed avatar and track artwork |

Unsplash's current license is at <https://unsplash.com/license>. Image-search labels suggested these were free Unsplash photos, but this repository does not retain a verified source page or model release for each individual image. **Before a public launch, verify the individual source page, license and model-release status or replace each fixture with approved, released assets.** Do not present these illustrative fixture portraits as real Cultured members. The Fingerprint gallery itself only shows image URIs a device owner selects from their library; those photos are stored on-device and are not uploaded by this app.
